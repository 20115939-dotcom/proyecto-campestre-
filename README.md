# 🍗 Sistema de Auto-Pedido — Pollo Campestre SRL

## 📌 Descripción General
Este repositorio contiene el desarrollo completo del **Sistema de Auto-Pedido 
y Tecnificación del Servicio a Domicilio** para Pollo Campestre, sucursal 
Santa Rosa de Lima, departamento de La Unión, El Salvador.

El sistema fue diseñado para optimizar la eficiencia operativa mediante 
terminales de auto-pedido con pantalla táctil, reduciendo los tiempos de 
espera en un 40% y expandiendo el servicio a domicilio mediante nodos de 
despacho periféricos.
